# Goa Design

The [Goa Design Model](https://github.com/goadesign/model) is a golang framework for creating services and C4 diagrams.

The model DSL is described in Golang and it has a serve command to visualize the model in the browser.

The DSL was a bit ugly and difficult to understand, but it worked.

The command line tools are nice.
