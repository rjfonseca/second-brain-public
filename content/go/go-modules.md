# Go Modules
## Monorepo or Multi module projects
A repository may hold multiple modules and handle their version independendly.

A tag must be created with the module as prefix, like `mymodule/v1.1.1`

- [Managing Source (go.dev)](https://go.dev/doc/modules/managing-source#multiple-module-source)
- [Mod (go.dev)](https://go.dev/ref/mod#glos-semantic-version-tag)
- [Multiple Modules Within The Same Project (stackoverflow.com)](https://stackoverflow.com/questions/55041915/multiple-modules-within-the-same-project)
