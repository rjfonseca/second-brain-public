# Model Context Protocol (MCP)

## O que é
- [Intro (modelcontextprotocol.io)](https://modelcontextprotocol.io/docs/getting-started/intro)

É um protocolo para comunicar com [Large Language Model (LLM)](large-language-model-llm.md).

Ele traz padronização, facilitando integração com LLMs.

A ideia é escrever um servidor que provê ferramentas e é usada uma LLM para processar um prompt e montar chamadas para essas APIs. A LLM cuida de entender qual função chamar e com quais parâmetros.
