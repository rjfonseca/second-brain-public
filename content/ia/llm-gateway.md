# LLM Gateway

Usar LLMs diretamente possui riscos pois o controle sobre tokens, custo e segurança fica descentralizado.

Usar um gateway ajusta a organizar isso e é comum em empresas o acesso a LLMs ser feito através de gateways centralizados.

Projeto interessante: https://github.com/maximhq/bifrost
