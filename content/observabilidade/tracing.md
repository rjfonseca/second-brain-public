# Tracing

## Trace-Context
It is a way to propagate trace context information between systems.

Defined in this [W3C Recommendation](https://www.w3.org/TR/trace-context/).

## Baggage
User defined properties.

Defined in this [W3C Draft](https://w3c.github.io/baggage/).
